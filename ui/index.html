Nexus — Multi-Agent Orchestration Runtime

A Rust runtime that schedules a dependency DAG of agent tasks, runs ready work in parallel, supervises each worker with evidence-based liveness (heartbeats, not wall-clock guesses), auto-recovers transient failures, pauses for human decisions, and governs token cost.
